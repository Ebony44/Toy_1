// resistances mitigation on Last Epoch
// LE -> math is enemy damage *( 1 + enemy Penetration - your resistance ) * ( 1 - your resistance )
// // LE -> 75% resistance, 120 dmg, 120 * (1 + 0.75 - 0.75) * (1 - 0.75) = 30 dmg
// // LE -> 50% resistance, 120 dmg, 120 * (1 + 0.75 - 0.5) * (1 - 0.5) = 75 dmg

// LE -> math is enemy damage *( 1 + enemy Penetration - your resistance )
// incoming damage = 100
// at 0% -> 100 * (1 + 0.75 - 0) = 175
// at 50% -> 100 * (1 + 0.75 - 0.5) = 125
// at 75% -> 100 * (1 + 0.75 - 0.75) = 100
